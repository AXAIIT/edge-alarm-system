## Pipeline

```text
VideoSource
-> DetectorService
-> DetectionEventQueue
-> EventTrigger
-> EventPackage
-> ModelRouter
   -> text_llm: Qwen3-1.7B async_event_triggered
   -> image_vlm: Qwen3-VL async_roi_only_low_frequency
   -> video_vlm: disabled_by_project4_decision
-> AlarmJsonBuilder
-> SchemaValidator
-> AlarmSink
```

## 当前结论

Jetson 和 RK3588 事件规则已经按 05H 收敛为 `visual_detection` 候选告警语义：`person_presence`、`vehicle_presence`、`multi_object_scene`。模型路由按项目四结论收敛：检测为高频主线，文本和图文为低频异步，视频模型禁用。Jetson `20260708_jetson_8gb_alarm_system_realtime30min_required_v1` 已完成 30 分钟 required run，随后 `20260713_jetson_8gb_alarm_service_resident_detector_smoke_v1` 又补齐了 Project5 本地 resident detector 在线事件链路：Project5 local TensorRT detector `resident_process` 612.629 秒内在线生成 event/alarm/per-event/stability，`event_count=136`、`alarm_count=136`、`llm_call_count=0`、`vlm_call_count=0`、`drop_count=0`。RK3588 方面，`20260710_rk3588_8gb_alarm_service_resident_detector_smoke_v2` 已证明 Project5 本地 resident detector 在线事件链路可用；`20260708_rk3588_8gb_alarm_system_realtime30min_required_v1` 作为 30 分钟 required interface 证据；`20260708_rk3588_8gb_alarm_system_rkllm_text_smoke_v1` 复用 required 事件输入补齐真实 RKLLM 文本解释；最终 `20260713_rk3588_8gb_alarm_service_resident_required_v2` 又把 resident detector、resident text、resident VLM 放进同一 30 分钟窗口，在线生成 200 行 event package、200 行 Alarm JSON、200 行 per-event benchmark 和 1 行 stability raw，`llm_call_count=2`、`vlm_call_count=2`、`event_queue_depth=24`、`drop_count=0`。在此基础上，`20260713_rk3588_8gb_alarm_service_resident_target_v2` 又把同一条在线事件链路稳定扩展到 2 小时 target。

真实 VLM 的下一步不是继续复用旧 event package。旧 required/Astra 事件只包含 `roi_boxes`，`keyframe_path`/`roi_paths` 为空，无法作为 Qwen3-VL 输入。`20260708_rk3588_8gb_alarm_system_vlm_assets_smoke_v1` 已按新流程执行：Project3 开启 `SAVE_OUTPUT_VIDEO=1`，`extract_event_assets_from_video.py` 生成 3 行带 keyframe/ROI 的 event package，VLM 使用 `run_vlm_roi_qa.py --mode rkllm_multimodal` 调用 Project4 RK3588 多模态 runner，3 行 runtime 均 pass。历史 mt128 输出中第二条 `multi_object_scene` 被截断；mt384 回归 rows=3、bad=0，三条摘要完整。该结论仍限定为 cold-start single-shot VLM runtime smoke，不能写成 resident VLM 或检测/VLM 并发稳定性通过。
